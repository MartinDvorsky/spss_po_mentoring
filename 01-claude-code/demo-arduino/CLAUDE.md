# Arduino demo (SPŠ mentoring)
- PlatformIO projekt, doska Arduino Uno (env `uno`), kód v `src/main.cpp`
- Build: `pio run` · Upload: `pio run -e uno -t upload` · Simulácia: Wokwi (`diagram.json`)
- Zapojenie: LED na pin 9 (cez 220 Ω), tlačidlo na pin 2 proti GND (INPUT_PULLUP)
- Komentáre a výpisy po slovensky bez diakritiky
- Po každej zmene over, že `pio run` prejde
